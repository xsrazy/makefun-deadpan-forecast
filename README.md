A deadpan weather forecast for a city that does not exist: one line, at most 160 characters, absurd yet believable enough to read like a real TV broadcast. The entry writes a single forecast line for the fictional city of Grimbleton to `entry.txt`.

## Run it

```sh
python3 main.py
```

The forecast is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if the variable is unset). Python standard library only, no dependencies, fully deterministic.

## The forecast

> In Grimbleton, highs of 58, lows of 57, and fog so thick the lighthouse has filed a formal complaint.

Ten candidate lines were written and judged head-to-head against the judge's criteria (on-subject forecast, funnier, more vivid, believable broadcast tone, tight use of characters). The full list and the reasoning are in [CANDIDATES.md](CANDIDATES.md).
